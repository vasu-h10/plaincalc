# PlainCalc

A minimal offline Android calculator with arithmetic, decimals, percent, sign change, backspace, and parentheses in expressions.

Privacy: no internet permission, ads, analytics, trackers, or accounts. Calculations happen on-device.

Build requirements: Android SDK, Java 17, Gradle compatible with Android Gradle Plugin 8.7.3. Run `gradle assembleDebug`.
